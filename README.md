# React To-Do Application

A basic To-Do application built with React to manage daily tasks.

## 🚀 Features
* **Add Tasks** - Create new items using an input form.
* **Complete Tasks** - Check off completed items with cross-out styling.
* **Delete Tasks** - Remove items from the list completely.
* **Edit Tasks** - Update existing task text in place.
* **Filter Views** - Switch between All, Pending, and Completed tasks.
* **Save Data** - Tasks persist using browser localStorage.
